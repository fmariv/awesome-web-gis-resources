# Awesome Web GIS Resources [![Awesome](https://awesome.re/badge.svg)](https://github.com/sindresorhus/awesome)

A curated collection of web-based GIS tools, geospatial APIs, mapping utilities, and resources for working with geographic data.

Contributions are welcome! Please read the [contribution guidelines](CONTRIBUTING.md) before submitting a resource. Open-source, free, and commercial tools can be included when they provide clear value and are described transparently.

Inspired by [awesome-gis](https://github.com/sshuair/awesome-gis).

## Data generation

### Terrain and hillshade
- [Eduard](https://eduard.earth/) — Terrain and hillshade visualization.

## Data access and downloading

- [geodatadownloader](https://geodatadownloader.com/) — Geospatial data downloading utility.
- [Overpass Ultra](https://overpass-ultra.trailsta.sh/) — Query and explore OpenStreetMap data with Overpass.
- [GeoDesk](https://www.geodesk.com/) — Open-source spatial database engine for querying and analyzing OpenStreetMap data.

## Data visualization and cartography

### Color palettes and map design
- [ColorBrewer](https://colorbrewer2.org/#type=sequential&scheme=BuGn&n=3) — Color schemes for thematic maps.
- [Bivariate choropleth color generator](https://observablehq.com/@benjaminadk/bivariate-choropleth-color-generator) — Generate palettes for bivariate maps.
- [Colours for maps](https://observablehq.com/d/ab5d7d5a5d9e9e16) — Explore color choices for maps.
- [Chroma.js Color Palette Helper](https://gka.github.io/palettes) — Build and preview color palettes.
- [MapColPal](https://mapcolpal.org) — Color palette resource for maps.

### Map visualization
- [Giro3D](https://giro3d.org/index.html) — Web-based 3D geospatial visualization.

### Cartographic utilities
- [Airtable CartoTools](https://airtable.com/embed/shr864WB1Q2ElGRpN/tblvGdsQDCgSexAAw?backgroundColor=blue&viewControls=on) — Cartographic tools and resources.

## Coordinate and format tools

### Coordinate conversion and reference systems
- [Calculation Hub Coordinate Converter](https://calculation-hub.com/geography/coordinate-converter) — Convert between decimal degrees, DMS, and UTM; not a general-purpose CRS transformation engine.
- [EPSG.io — Transform](https://epsg.io/transform#s_srs=4326&t_srs=3857) — Explore coordinate reference systems and transform coordinates.
- [ICGC Coordinate Calculator](https://www.icgc.cat/es/Administracion-y-empresa/Herramientas/Cambia-coordenada-formato/Calculadora) — Coordinate conversion calculator from the Institut Cartogràfic i Geològic de Catalunya.

### Geospatial format conversion
- [Convertbox](https://betaportal.icgc.cat/convertbox/) — Geospatial data conversion utility.
- [GDAL3.js](https://gdal3.js.org/) — Run GDAL capabilities in the browser.
- [GIS Toolbox](https://gis.taoliapp.com/) — Browser-based GIS conversion and coordinate tools.

### Projections and coordinate lookup
- [Geo-projections](https://www.geo-projections.com/) — Explore geographic map projections.
- [EPSG.io — Map](https://epsg.io/map#srs=4326&x=0.000000&y=0.000000&z=1&layer=streets) — Explore positions and reference systems on a map.
- [LatLong](https://www.latlong.net/) — Find latitude and longitude for locations.

## Geometry and data editing

- [Mapshaper](https://mapshaper.org/) — Edit, simplify, and convert vector geographic data.
- [Bounding Box](https://boundingbox.klokantech.com/) — Select geographic bounding boxes on a map.
- [geojson.io](https://geojson.io/#map=2/6.8/-19.3) — Draw and edit GeoJSON geometries on a map.

## Vector tiles and map styling

- [Maperture](https://stamen.github.io/maperture) — Compare web map styles.
- [Cartographer](https://chartographer.stamen.com/) — Inspect stylesheet properties by layer and zoom level.

## Geospatial APIs

### Location APIs
- [Mapbase](https://mapbase.dev/) — Location registry API for coordinates, administrative locations, custom zones, hierarchies, and geometries.
